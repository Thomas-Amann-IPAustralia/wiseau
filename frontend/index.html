    Engine
    Which should I choose?

    The fast parser (PyMuPDF / Mammoth) is the default: a digital document converts in about a second and returns the same Markdown every time; scanned pages are OCR'd at several seconds each. Choose highest fidelity when a document needs it — docling reads complex layouts, multi-column pages, tables and scans more faithfully, but runs an ML model on a free CPU: expect tens of seconds to a few minutes per document, longer after the service has been idle. It falls back to the fast parser automatically if it is unavailable. The engine applies to documents; a URL that serves an HTML page is always extracted the same way.
