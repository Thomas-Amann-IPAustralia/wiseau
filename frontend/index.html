Conversion engine

The fast parser (PyMuPDF / Mammoth) is the default: it answers in about a second and returns the same Markdown every time. Choose highest fidelity when a document needs it — docling reads complex layouts, multi-column pages, tables and scans far more faithfully, but it runs an ML model on a free CPU: expect tens of seconds to a few minutes per document, and longer still on the first request after the service has been idle. It falls back to the fast parser automatically if it is unavailable. The choice applies to documents; a URL that serves an HTML page is always extracted the same way.
