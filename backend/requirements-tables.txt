# Optional: tables on scanned pages, read cell by cell by Table Transformer (ADR-046).
#
# Off in the code, ON in the Docker image (ADR-047), which installs these, CPU
# PyTorch and the two models at build time. The default path reads a scanned
# table's words but not its columns; with this installed and WISEAU_TABLES=tatr,
# each table Table Transformer finds (and that passes the tabularity check) is
# written as a Markdown or HTML table. PyTorch adds about 1.9 GB to the image,
# ~1 GB of memory, and 1-4 s per scanned page on one thread (measured in
# docs/benchmarks/2026-11-09-tables.md).
#
# To enable:
#   pip install --index-url https://download.pytorch.org/whl/cpu torch==2.15.0 torchvision==0.29.2
#   pip install -r requirements-tables.txt
#   export WISEAU_TABLES=tatr
# The two models (230 MB, pinned revisions in parsers/tables.py) download from
# Hugging Face on first use; the image fetches them at build time instead
# (fetch_table_models.py). Without these packages the pass is skipped, never an
# error: the conversion is the default path's.
#
# transformers 5.x rejects the Table Transformer checkpoints' config; stay on 4.x.
transformers==4.57.6
timm==1.0.31
