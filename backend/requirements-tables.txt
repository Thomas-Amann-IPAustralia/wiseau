# Optional: the model passes on scanned pages (ADR-046, ADR-048).
#
#   - Tables, read cell by cell by Table Transformer (WISEAU_TABLES=tatr, ADR-046).
#   - Layout regions from PP-DocLayoutV3: block boundaries, headings, captions and
#     page furniture, regrouping the lines OCR already read (WISEAU_LAYOUT=ppdl, ADR-048).
#
# Off in the code, ON in the Docker image (ADR-047, ADR-048), which installs these,
# CPU PyTorch and the three models at build time. PyTorch adds about 1.9 GB to the
# image and ~1.5 GB of memory; on one thread tables cost 1-4 s and layout ~3.6 s
# per scanned page (docs/benchmarks/2026-11-09-tables.md, ADR-048).
#
# To enable:
#   pip install --index-url https://download.pytorch.org/whl/cpu torch==2.15.0 torchvision==0.29.2
#   pip install -r requirements-tables.txt
#   export WISEAU_TABLES=tatr WISEAU_LAYOUT=ppdl
# The models (~350 MB, pinned revisions in parsers/tables.py and parsers/layout.py)
# download from Hugging Face on first use; the image fetches them at build time
# instead (fetch_table_models.py). Without these packages a pass is skipped, never
# an error: the conversion is the default path's.
#
# transformers 5.x: PP-DocLayoutV3 exists only there. Table Transformer's pinned
# checkpoints load on it with one config normalisation (tables._config_5x), and give
# byte-identical tables to 4.57.6 on all 96 scored pages (ADR-048).
transformers==5.22.1
timm==1.0.31
# PP-DocLayoutV3's post-processing (its image processor requires cv2).
opencv-python-headless==5.0.0.93
