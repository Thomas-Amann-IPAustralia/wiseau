## Pitfalls

- torch's thread count is process-wide: keep `WISEAU_LAYOUT_THREADS` equal to
  `WISEAU_TABLE_THREADS`. 4 threads vs 1 can move a box by hundredths of a
  point (V4 p27: one line at ~50% overlap).
- Docker here: start `dockerd`. Build from a throwaway copy with the proxy CA
  in an early layer, and pass **only** `HTTPS_PROXY`: plain-HTTP apt through it
  gets a 405. Docker Hub rate-limits (429); pin the base image by digest to
  reuse BuildKit's cache.
- Set S has now been looked at by the layout work. Judge layout changes on set
  T, or draw a set U.
