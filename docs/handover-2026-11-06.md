## Pitfalls hit this session

- **Synthetic OCR fixtures with identical text on every line** stack the same
  letters into vertical strokes, and psm 3's layout analysis removes them as table
  rules ("Apple orchard line" → "e orchard ine"). Use varied lines.
- **The word-count guard catches lost text, not misread text.**
- **Measure the scale of a rule on a realistic page.** Stitching's gap limit is a
  share of the text width, so a narrow synthetic image makes ordinary cell gaps
  look wide. The end-to-end test page carries a full-width title for this reason.
- `grep` in a pipeline buffers a background run's progress lines until it exits.
  Watch the output directory instead.
- Re-creating the engines took ~15 minutes (CPU torch wheels for both venvs, plus
  the GLM-OCR weights at the revisions in `glm-ocr/Dockerfile`). Start that early.
