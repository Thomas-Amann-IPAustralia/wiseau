## Open decision: the cleaner (roadmap item 0.1)

`cleaner.py` turns ‘’ “” – — … into `' " - -- ...` on every conversion, so the
output does not show what was printed. **Recommended, narrowly:**
- drop only the quote, dash and ellipsis rows of `_CHAR_REPLACEMENTS`;
- keep the NBSP, zero-width and BOM rows;
- defer a `simplified` option and the CommonMark hard-break change.

This is a contract change: it needs an ADR, a `tech-spec.md` update (the line
near 376 that lists the replacements), an API version bump in `main.py`, and
updates to the two tests in `test_cleaner.py`. Check `chapters.py` contents
matching and `keywords.py` against curly punctuation. **The user has been asked
but has not answered yet. Don't build it without a yes.** The scorer
(`score.py`) drops punctuation, so this moves no benchmark number.

## Things to know

- **Invisible text counts as "has a text layer".** The default path's per-page
  test reads it, so every page of Vol 2 No 2 and of the patents is read
  natively today and never OCR'd. To benchmark OCR on those pages, the harness
  must render the image and OCR it, which `survey.py` and the Tesseract engines
  already do (`full=True`).
- **The new PBR scans are lower resolution than sets A–D.** Measured from each
  page's full-width image: Vol 2 No 2 has 21 of 40 pages at **150 dpi** (the
  rest about 300), and Vol 4 No 1 has 24 of 36 at **200 dpi** (the rest about
  300). The harness renders at 300 dpi, which upsamples those pages. This is a
  real-world degradation the preprocessing ablation (1.2) should cover, and the
  draw should stratify on it so the held-out set has both resolutions.
  Transcribe from the native image, zoomed, because upsampling adds no detail.
